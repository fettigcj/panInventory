# readme_createSitesPrismaSDWAN — Create Sites in Prisma SD‑WAN

Purpose
- Automate the creation (and possibly update) of sites and related objects in Prisma SD‑WAN based on input data.

Quick start
```
py .\createSitesPrismaSDWAN.py --help
```

Scheduling tip
- Typically ad‑hoc during deployments; if you routinely sync site data from a source of truth, schedule with care.

# readme_setPanoCIE — Configure Cloud Identity Engine (CIE) for Panorama

Purpose
- Assist with configuring Panorama to use Cloud Identity Engine (CIE) as a user and group source.

Quick start
```
py .\setPanoCIE.py -c panCoreConfig.json -L setPanoCIE.log
```

Scheduling tip
- Typically a setup task; not normally scheduled.

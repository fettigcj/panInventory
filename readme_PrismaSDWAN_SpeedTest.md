# readme_PrismaSDWAN_SpeedTest — Prisma SD‑WAN Speed Test Helper

Purpose
- Exercise/validate throughput to or across Prisma SD‑WAN sites and record simple results for troubleshooting.

Quick start
```
py .\PrismaSDWAN_SpeedTest.py --help
```

Scheduling tip
- Wrap in a shell/batch and schedule for periodic baselines during maintenance windows.

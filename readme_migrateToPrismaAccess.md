# readme_migrateToPrismaAccess — Assist Migration to Prisma Access

Purpose
- Utilities to help prepare and migrate objects/policies to Prisma Access (discovery, transforms, exports).

Quick start
```
py .\migrateToPrismaAccess.py --help
```

Scheduling tip
- Generally ad‑hoc during migration waves; schedule only if routinely synchronizing data from Panorama to Prisma Access.
